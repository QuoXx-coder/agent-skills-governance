# 多智能体 Skill 治理手册

## 一句话

给每份可共享 Skill 一个唯一的家，让每个宿主只通过受管入口使用它。

## 三个概念

- **真源**：唯一权威目录，默认 `~/.agents/skills`。
- **入口**：宿主读取真源的方式：`direct`、`symlink` 或 `managed_copy`。
- **副本**：只在不能链接时使用；受管副本必须带 `.agent-skill-source.json`。

## 决策

| 情况 | 做法 |
| --- | --- |
| 项目专属 Skill | 保留在项目中，不收进公共真源。 |
| 通用独立 Skill | 放入公共真源，刷新锁文件后同步。 |
| Marketplace / 内置能力 | 保持宿主专属；同名时登记结构化 `host_exception`，不互相覆盖。 |
| 新智能体 | 先 `doctor` / `discover`，核对官方机制和本机路径，再展示接入计划。 |

一个宿主中的同名 Skill 只能有一个权威来源。发现问题只代表需要评估，不代表获得删除、移动或覆盖的授权。

## 日常

定期运行 `doctor` 或 `audit --strict`。更新已登记 Skill 时只改真源，刷新锁文件，再同步并审计。哈希漂移为零才算完成。
